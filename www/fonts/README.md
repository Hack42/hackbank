# Cyber (OCR-A)

`OCRA.otf` is the unmodified OCR-A OpenType font from Matthew Skala's
[Tsukurimashou OCR package, version 0.3.1](https://tsukurimashou.org/ocr.php.en),
downloaded from https://tsukurimashou.org/files/ocr-0.3.1.zip.
Button Studio calls this font **Cyber**; the font's internal names are unchanged.

The original copyright, credit, distribution terms and disclaimer from
`msk-ocra.mp` are preserved in [OCRA-NOTICE.txt](OCRA-NOTICE.txt).
Skala releases his contribution to the public domain; the original terms
require retaining the notices and prohibit charging for distributing the
font beyond reasonable copying or communications costs.

The font loads from this directory, with no external font service. Its glyph
coverage is limited; characters it lacks use the browser's monospace fallback.
The bundled face is regular; the browser synthesizes heavier weights selected
in Button Studio.
